# CLI packaging and session lifecycle — 2026-09-27

The npm executable is `visulia` (Node.js 24+). Its interactive menu connects to a
configured server, creates a session/run, sends heartbeats, generates demo requests,
uploads an explicitly selected file, changes configuration, checks/ingests/reparses,
and executes ES|QL. Quit, signals and input disconnect request session deletion.
The owner token stays in memory. Remote origins require HTTPS; loopback HTTP is
allowed for local tests. Redirects are rejected rather than forwarding credentials.
